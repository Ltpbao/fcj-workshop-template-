# Week 7 Worklog (15/06/2026 – 21/06/2026)

#### 1. Weekly Objectives
- Learn the AWS SDK for Java with Amazon S3 Client.
- Implement basic Amazon S3 operations in Java.
- Understand object management and access permissions in Amazon S3.

#### 2. Technical Activities Summary
This week focused on integrating Amazon S3 into the GearStore backend using the AWS SDK for Java. Studied the Amazon S3 Client API and learned how to authenticate applications using AWS credentials. Implemented core object management operations, including uploading files with **PutObject**, deleting files with **DeleteObject**, and configuring public read access for uploaded objects. Tested these features to ensure files were correctly stored, managed, and accessible through Amazon S3.
